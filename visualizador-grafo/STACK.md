# Stack — Visualizador de grafo (Fase 3)

## Resumen

| Capa | Tecnología |
|------|------------|
| Marcado | HTML5 |
| Estilos | CSS3 (custom, sin Bootstrap/Tailwind) |
| Script | JavaScript ES6+ (vanilla, sin React/Vue) |
| Grafo en pantalla | [vis-network](https://visjs.github.io/vis-network/) (vis.js) |
| Fuentes | [DM Sans](https://fonts.google.com/specimen/DM+Sans), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) |
| CDN | [unpkg](https://unpkg.com/) (`vis-network.min.js`) |
| Build | Ninguno (abrir `index.html` directamente) |

## Archivos propios

- `index.html` — layout
- `styles.css` — UI (tema oscuro, cards, leyenda)
- `grafo-data.js` — datos demo + BFS + adyacencia
- `app.js` — integración vis-network
